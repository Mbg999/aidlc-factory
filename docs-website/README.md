# AIDLC Factory Documentation Website

Documentation site for the [AIDLC-Factory](https://github.com/Mbg999/aidlc-factory) multi-agent orchestrator.

Built with React, Vite, Tailwind CSS, and Lucide icons.

## Run Locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:3000`.

## Build

```bash
npm run build
```

Output goes to `dist/`.
